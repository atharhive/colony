# Launch

Everything a reviewer or a visitor needs, and the short list of things only the owner can
do.

## What is done

- [x] Public repository with an MIT licence
- [x] Installable package (`pip install -e .`, `colony` on PATH)
- [x] 54 tests, offline, no wallet and no network
- [x] One real paid run committed under `evidence/`, with memo, receipts and bundle hash
- [x] Verifier that recomputes the bundle hash and survives a tamper attempt
- [x] Demo video, 3:31, recorded from a live session
- [x] README with a demo banner, badges, quickstart, architecture and honest limits
- [x] Docs: product, positioning, pricing, decisions, usage, troubleshooting, evidence index
- [x] GitHub topics set
- [x] Release `v3.0.0` with the demo attached

## What only the owner can do

1. **Star `telegraphprotocol/bounties`.** Required for every track.
2. **Star this repo.** It currently shows zero, which is the first thing a judge notices.
3. **Submit the Anjoman form**, two entries: Apps & Agents (Colony, Mission 03) and
   Evaluators. Copy is in `SUBMISSION.md`.
4. **Post the launch tweet** (draft in `docs/GROWTH.md`, video attached).
5. **Post the showcase thread** in the Telegraph Discord.
6. **Set the social preview** (Settings, Social preview, upload `docs/demo/banner.gif`).
   GitHub does not allow this through the API.
7. **Pin the repo** on the profile for the duration of the season.

## Order that works

Star the bounties repo first, because the form asks for it. Then submit the form, because
prizes are gated on it. Then post, because a post with a submission behind it is a
different conversation.

## What is still missing, honestly

- No miner. The third track is empty, and the README does not pretend otherwise.
- One mission only, not the fifteen. Depth over breadth was the deliberate trade after the
  feedback that four shallow workflows were worth less than one real product.
- Growth points need three dated public updates. One exists; two to go.
